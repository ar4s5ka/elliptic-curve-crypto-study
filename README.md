# 楕円曲線暗号の学習用実装

Pythonで楕円曲線の点演算、ECDHの公開鍵生成、
EC ElGamalの暗号化・復号を確認するプロジェクトです。

## ファイル構成

- `es.py`：楕円曲線の点加算・スカラー倍
- `ECDH.py`：公開鍵の生成
- `EC_ElGamal.py`：暗号化・復号
- `main.py`：実行例
- `test.py`：基点の位数と暗号化・復号のテスト

## 実行方法

Python 3.8以上を使用します。外部ライブラリは不要です。

```sh
python main.py
```

## テスト

```sh
python test.py
```

## 注意

学習用の小さなパラメータを使用しています。
実際の機密情報の暗号化には決して使用しないでください。
